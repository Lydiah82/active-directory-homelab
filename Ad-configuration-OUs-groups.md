## Organisational Units and Security groups configuration
- Created Organisational Units(OUs) based on Geographical Regions to support structured administartion
- The following OUs were configured
- **Africa**
  - Users
  - Computers
  - Servers
- **USA**
  - Users
  - Computers
  - Servers
- **Asia**
  - users
  - Service accounts
- This OU structure separates objects by function and Region to improve managability and scability of the Domain environment
